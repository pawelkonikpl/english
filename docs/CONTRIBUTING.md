# Contributing Guidelines

Thank you for considering contributing!

## Ways to Contribute

### 🐛 Report Bugs
Found a bug? [Open an issue](../../issues/new?template=bug_report.md)

### 💡 Suggest Features
Have an idea? [Open a feature request](../../issues/new?template=feature_request.md)

### 📖 Improve Documentation
- Fix typos
- Clarify instructions
- Add examples
- Translate to other languages

### 🎯 Add Examples
Share your learning journey (anonymized)!

### 🛠️ Build Integrations
- Discord/Telegram bots
- Mobile apps
- Browser extensions

---

## Development Guidelines

### Code Style
- Clear, descriptive names
- Comment complex logic
- Follow existing patterns

### Commit Messages
```
Good:
- "Add B2 vocabulary list"
- "Fix: Review schedule calculation"
- "Docs: Clarify assessment process"

Bad:
- "Update"
- "Fix stuff"
```

---

## Pull Request Process

### Before Submitting
1. Test thoroughly
2. Update documentation
3. Add examples if needed
4. Check for typos

### PR Template
```markdown
## Description
[What does this PR do?]

## Type of Change
- [ ] Bug fix
- [ ] New feature
- [ ] Documentation

## Testing
[How did you test this?]

## Checklist
- [ ] Tested changes
- [ ] Updated docs
- [ ] Added examples
```
