# Getting Started with English Learning AI Agent

## For Complete Beginners

### Step 1: Choose Your AI Platform

**Claude (Recommended)**
- Go to https://claude.ai
- Create a free account
- Start a new conversation

**ChatGPT**
- Go to https://chat.openai.com
- Create an account
- Start new chat

### Step 2: Initial Assessment

Copy and paste:

```
I want to start learning English with the AI Learning System.
Please conduct an initial assessment to determine my level.
```

### Step 3: Answer Questions

The AI will ask 3-5 questions. **Be honest!**

### Step 4: Save Your File

1. Copy the ENTIRE text AI generates
2. Open a text editor (Notepad, TextEdit)
3. Paste the text
4. Save as `english-learning.md`

### Step 5: Start Learning!

1. Open new AI chat
2. Upload `english-learning.md`
3. Press Enter
4. Choose a lesson
5. After lesson, copy updates to your file

---

## Tips for Success

- Practice 20-30 minutes daily
- Don't skip reviews!
- Use new words in sentences
- Track your progress
- Join the community

---

## Troubleshooting

**Q: AI doesn't recognize my file**
A: Make sure file has system prompt at top

**Q: Lost my file**
A: Always keep backups in cloud storage

**Q: Can I use multiple AIs?**
A: Yes! Same file works everywhere
